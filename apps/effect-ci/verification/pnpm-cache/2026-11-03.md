install against the current checkout. Vite+ remains responsible for invalidation.

Process guidance: the host README and SELF-HOST deployment guides own sequence and

its path-based cache identity, and its cache-preserving checkout. Vite+ `1.0.0`'s

preserves the real metadata rather than overriding its dependency inputs.

prepared separately and awaits approval. No claim of fresh GitHub workload proof

The second run logged `$ vp build ◉ cache hit, replaying`, as well as explicit

| Measured phase | First fixed run | Unchanged cached run |
| --- | ---: | ---: |
| Source checkout, package-manager discovery/setup | 15.582 s | 24.975 s |
| Cache lookup and materialization | 0.320 s | 13.375 s |

Phase rows are non-overlapping native step durations. Queueing, bookkeeping gaps,
cache-pointer writes, identity calculation, and client/network overhead account
for the remaining wall time. The larger cached wall time is observed variability,
not a speedup. This proves hosted task reuse; it does not prove a fast overall
remote invocation. Explicit `--local` remains the speed escape hatch.

[Machine receipt](./2026-11-03.json "source") retains source revisions, snapshot
IDs, task messages, command output, exit codes, and separated timings. Full raw
agent envelopes are retained in this chat's `pnpm-cache` artifact directory.
