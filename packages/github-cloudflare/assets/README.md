# Chart font

Unmodified ABeeZee Regular from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/abeezee

The adjacent OFL.txt contains its copyright notice and SIL Open Font License.
The `.ttf.bin` extension lets the Workers Vite plugin bundle the font as a Data
module (ArrayBuffer), not a public URL. No system fonts or remote assets are used.
