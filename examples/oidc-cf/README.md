# Deploy with cf using short-lived credentials

> Can I keep my GitHub Actions deployment and replace its stored Cloudflare secret with a temporary token?

Add one authentication step, then keep `cf deploy`. Execution stays on GitHub.
The [GitHub runner app](../../apps/github-actions-runner/OIDC.md) issues a 15-minute
**Individual Workers Editor** token for this Worker, and the action revokes it after the job.

## Try it here

```sh
gh workflow run oidc-live-proof.yml --ref codex/oidc-runner-integration -f example=cf
gh run list --workflow oidc-live-proof.yml --branch codex/oidc-runner-integration
```

The workflow checks own-Worker access, other-Worker and R2 denials, deployment,
the served response, and revocation. This repository's configured grant permits
that exact workflow and branch. A fork needs its own setup.

## Use your account

1. Bootstrap `effect-ci-oidc-cf` once using operator credentials. Editor can update
   it but cannot create it. The Worker needs no storage bindings or routes.
2. Follow [OIDC setup](../../apps/github-actions-runner/OIDC.md). It can reuse the account
   and subdomain generated by the native self-hosting setup; there is no third app.
3. Copy [deploy.yml](./.github/workflows/deploy.yml) to the repository root as
   `.github/workflows/oidc-cf.yml`, and authorize that path/ref in setup with
   `--workflow .github/workflows/oidc-cf.yml`. Nested example workflows are not
   discovered by GitHub automatically.
4. Dispatch the copied workflow. For a different repository, adjust its working
   directory and use the authentication action at a reviewed commit SHA.

```yaml
# The job also needs permissions: id-token: write and contents: read.
- uses: ./.github/actions/cloudflare-auth
  with:
    broker-url: ${{ vars.EFFECT_CI_OIDC_BROKER_URL }}
    worker: effect-ci-oidc-cf
    scopes: workers:edit
- run: pnpm --dir examples/oidc-cf run deploy
```

Custom scopes must first be authorized in the broker's allowlist. Requested scopes
are a subset, never an instruction to grant more authority. R2 is not included.
[Setup, limitations and live evidence](../../apps/github-actions-runner/OIDC.md).
